# Apply shared figure rules to every data figure

Status: Owner decision, 2026-10-09.

The owner asked for one figure pass across their repositories: "use figure
composer and figure style for these repos and redo the charts, bars, plots,
tables, everything that shows visual imagery through data". This is the owner
authorization that the AGENTS.md rule against cross-repository template passes
asks for.

In this repository the pass redraws 30 data figures and one table image from
committed run files and results. No result file, Markdown results table or
analysis step changed. [Data and figures](../data-and-figures.md#figure-rules-and-redraw)
holds the rules, the redraw command and the images that were not redrawn.
