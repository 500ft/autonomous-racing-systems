Keep the physical owner register and the nominal design register separate.
Do not overwrite the six pending rows in parameters.csv. If new nominal values

=======================================================

Goal: challenge the simulator/controller chain with a deliberately changed plant

only and does not establish physical performance.

Do:

  - Sweep a small predeclared matrix: model wheelbase 0.3302 m versus selected
    chassis 0.324 m; mass 3.74 kg versus nominal 4.42 kg; tire/friction scale
    at 0.8/1.0/1.2; command delay at 0/20/50 ms; steering saturation and one
    sensor-dropout case where the existing APIs support it.

  - Use a deterministic run ID derived from config hash and source commit.
Done when:
  - The matrix is small enough to run in under 15 minutes in CI or a developer
    laptop, yet contains at least one nominal and one changed-plant case.
  - Tests reject missing factors, duplicate cases, nonfinite values, and changed
    seeds that are not recorded.

W2.2 — Run and validate the mismatch sweep
Files: experiments/vehicle_mismatch_sweep.py,
       experiments/test_vehicle_mismatch_sweep.py,
       runs/vehicle_mismatch_sweep/results.csv,
       runs/vehicle_mismatch_sweep/metadata.json.
Do:
  - Record lap completion, lap time, RMS/max cross-track error, steering effort,

  - Re-running with the same source/config hash reproduces the metrics within a
    declared floating-point tolerance.
  - At least one changed-plant result differs materially from the nominal result
    or the report explicitly says the factor was not influential in this model.
  - MPC timing keeps both p95 and worst-case values; the known max-spike risk
    cannot disappear into an average.
